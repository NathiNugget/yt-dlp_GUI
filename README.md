## Getting Started

Welcome to my application. This app implements simple GUI for yt-dlp. This app assumes you are using Windows as well as having yt-dlp and FFMPeg on your Path
The latest version is compiled with JDK 22.0.1, so you should have a JRE version on that version or newer. 
To download, head to releases or [click here](https://github.com/NathiNugget/yt-dlp_GUI/releases/download/1.1/yt-dlp_GUI.jar) to download Release 1.1
